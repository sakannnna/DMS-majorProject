## 四 校验

### T05 合法值精确处理与错误输入（R04～R06）

**目的、方式与前置**：对对应题目定义直接调用答案规范化函数；20组输入，不涉及HTTP或数据库。规范化指去除文本首尾空白、将合法数字转换为存储类型等处理，不能只检查“不报错”。

**操作与预期**：逐组传入下表答案，接受时比较精确值，拒绝时检查业务异常。

| 输入与约束 | 预期处理结果 |
| --- | --- |
| 单选a；未知bad；必答null | a原值；后两项拒绝 |
| 多选恰好2，输入[a,b]、[a]、[a,b,c] | 仅[a,b]接受且返回[a,b] |
| 多选[a,a]、未知[bad] | 拒绝重复及未知选项 |
| 文本2～3字，“  中文  ”、“字”；最多3字“四个汉字” | 第一项精确为“中文”；后两项拒绝 |
| 数字整数0～120，0、120、121、-1 | 前两项精确为Decimal128的0与120，后两项拒绝 |
| 整数题1.5；数字NaN、Infinity、abc、1e9999 | 均拒绝，不接受非有限或不可表示值 |

**实际与证据**：A合法值只判断非空，不足以证明规范化正确；C加强精确值和数字类型比较，F回归全部通过。该历史差异不抹去，也不另造失败。
