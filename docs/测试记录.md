## 环境与执行方法

2026-10-16，Windows，Python 3.12.10，MongoDB 8.3.11，FastAPI 0.143.2，PyMongo 4.19.0，pytest 9.1.1。完整依赖见 [requirements.txt](../requirements.txt)。当前结果对应本批增量修改的代码；历史基线定位由README维护。

先按 README 启动 MongoDB，再在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest -q --junitxml=docs/evidence/pytest.xml
```

每个集成测试建立随机命名 `survey_course_test_<UUID>` 的独立库，创建账号 owner，并启动测试应用初始化四集合、validator 和索引；结束后只清理本次生成的库。普通数据库 `survey_course` 不被清理。测试使用的账号密码为专用虚构数据，无真实用户信息。
