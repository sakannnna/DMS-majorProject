# 第一阶段测试记录

测试针对已确认的[需求与设计](需求与设计.md)。自动用例实现在 [test_system.py](../tests/test_system.py)，使用真实 MongoDB；表内是可复现步骤与预期，执行历史单列，未将计划写为结果。

## 环境与执行方法

2026-10-16，Windows，Python 3.12.10，MongoDB 8.3.11，FastAPI 0.143.2，PyMongo 4.19.0，pytest 9.1.1。完整依赖见 [requirements.txt](../requirements.txt)。基线版本见 Git 标签 `stage1-v1`；执行时为该基线的工作树。

先按 README 启动 MongoDB，再在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest -q --junitxml=docs/evidence/pytest.xml
```

每个集成测试建立随机命名 `survey_course_test_<UUID>` 的独立库，创建账号 owner，并启动测试应用初始化四集合、validator 和索引；结束后只清理本次生成的库。普通数据库 `survey_course` 不被清理。测试使用的账号密码为专用虚构数据，无真实用户信息。
